# Hardware

## Parol6
- opensource 6axies robot arm
- open-loop control with STM32 based board
- Jetson Orin Nano Super 8GB
- IMX219-75 wrist camera
  
## MiniParol6 (Leader arm)
- identical URDF is used for compatibility with Parol6
- 0.7 : 1 scale
- Servo motor: STS3215 with URT-2 from Feetech
